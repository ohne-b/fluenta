## Download

Download the latest version from [GitHub Releases](https://github.com/ohne-b/fluenta/releases).

| Platform | Files |
| --- | --- |
| Windows x64 | Portable `.exe` or `-setup.exe` installer |
| Linux x64 | `.AppImage` or `.deb` |
| macOS 15+ Intel / Apple Silicon | Universal `.dmg`; `.app.tar.gz` for updates |

Each release includes `SHA256SUMS.txt`, signed update metadata, and a corresponding-source archive. See the [changelog](CHANGELOG.md).

## Features

- Foundation lessons, grammar tables, and practice with English or German explanations.
- Topic missions connecting reading, vocabulary, listening, writing, and speaking.
- Personal vocabulary with contextual meanings, notes, and FSRS spaced review.
- Saved drafts, revisions, and self-review rubrics for longer answers.
- Included Spanish speech synthesis and recognition; optional local AI tutor.
- Light and dark themes, local progress, and portable backups. No account required.

## Data

Fluenta stores its data in:

```text
Windows: %APPDATA%\org.fluenta.desktop\
macOS:   ~/Library/Application Support/org.fluenta.desktop/
Linux:   $XDG_DATA_HOME/org.fluenta.desktop/
         or ~/.local/share/org.fluenta.desktop/

org.fluenta.desktop/
|-- learner/       progress database, courses, recordings, recovery snapshots
|-- models/        optional tutor model
`-- cache/speech/  generated audio
```

Use **Settings → Your data** to export or restore progress, notes, drafts, conversations, and recordings. Studio uses a separate `org.fluenta.studio` profile. See [privacy and recovery](docs/privacy.md).

## Courses

The included library has 36 foundation lessons, 17 grammar courses, six connected migration chapters, and seven other introductory topic missions. Grammar help opens beside lessons without losing an answer.

General Abitur practice includes source analysis, discussion, mediation, and independent challenges. This is a starter library, not complete syllabus coverage or a certified A1–B2 course. Longer answers use self-review; speech recognition does not grade pronunciation. [Curriculum scope and sources](docs/connected-learning.md).

## Speech and tutor

Piper and whisper.cpp ship with a Spanish voice and Whisper Small. They work without additional downloads. Listening generated by Piper is synthetic speech.

Download the optional **Gemma 4 E2B** model in Settings (3.11 GB). The tutor runs through llama.cpp and cannot change grades or review schedules. Inference currently uses the CPU with up to six threads; 16 GB RAM is recommended. Model downloads need internet; using an installed model does not.

## Development

Tauri 2 and Rust, with React, TypeScript, and SQLite. Install Node.js 24, Rust via rustup, CMake 3.26+, and [Tauri's platform prerequisites](https://v2.tauri.app/start/prerequisites/). Windows also needs Visual Studio C++ Build Tools.

```sh
npm ci
npm run contracts
npm run content:build
node scripts/prepare-runtime.mjs
node scripts/prepare-notices.mjs
npm run desktop:dev
```

The preparation scripts download pinned speech engines and models. `npm run dev` starts the renderer alone; storage and audio require the native app.

```sh
npm run check
cargo run -p fluenta-speech --example verify_speech
cargo build -p fluenta-desktop
npm run test:e2e
```

The desktop suite runs against a real Windows WebView2 app with an isolated profile. `npm run studio:dev` opens the separate content editor. [Authoring](docs/content.md) · [Verification](docs/verification.md).

The **Check** workflow runs on pushes and pull requests. **Release** builds the Windows, Linux, and universal macOS packages and uploads them to a draft release. See [release instructions](docs/releases.md) for signing and local builds.

## Troubleshooting

### Windows blocks the executable

Windows releases are not Authenticode-signed. Confirm the download came from this repository and compare its checksum before choosing **More info → Run anyway**. The Setup EXE includes the offline WebView2 installer. The portable EXE requires WebView2 to be installed already and extracts its bundled resources temporarily while running.

### macOS blocks the app

The macOS build is ad-hoc signed, not Apple-notarized. After verifying its source and checksum, use macOS **Privacy & Security → Open Anyway** if offered.

### Linux requirements

Packages target Ubuntu 24.04 or compatible distributions. AppImage needs FUSE 2 (or `--appimage-extract-and-run`). Install the DEB through APT to resolve system dependencies.

### An update fails

Check the connection and retry in Settings, or download a new release manually. Progress stays in the data directory. Signed updates support Windows Setup, AppImage, and macOS. Update the portable EXE and DEB manually; running a Windows in-app update installs the Setup edition.
